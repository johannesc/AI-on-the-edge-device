# Parameter `IO13`
Default Value: `input-pullup disabled 10 false false`

!!! Warning
    This is an **Expert Parameter**! Only change it if you understand what it does!

This parameter can be used to configure the GPIO `IO13` pin.

!!! Note
    This pin is usable without known restrictions!

Parameters:

- `GPIO 13 state`: One of `input`, `input pullup`, `input pulldown`, `output` or `servo`.
- `GPIO 13 use interrupt`: Enable interrupt trigger
- `GPIO 13 PWM duty resolution`: LEDC PWM duty resolution in bit
- `GPIO 13 enable MQTT`: Enable MQTT publishing/subscribing
- `GPIO 13 enable HTTP`: Enable HTTP write/read
- `GPIO 13 name`: MQTT topic name (empty = `GPIO13`). Allowed characters: `a-z, A-Z, 0-9, _, -`.

### Servo mode
In `servo` mode, a RC servo (e.g. SG90) connected to this pin presses a button before every picture is taken, e.g. to switch on the display of a digital meter.
See the parameters `ServoRestAngle`, `ServoPressAngle`, `ServoPressDuration` and `ServoWaitAfterPress`.

- Only one GPIO can be used in `servo` mode. The interrupt and PWM duty resolution settings are ignored.
- With MQTT or HTTP enabled, a press can also be triggered manually: publish `true` to the MQTT topic, or call `/GPIO?GPIO=13&Status=press`.
- Power the servo with 5 V from a supply that can deliver enough current (a servo can draw up to 1 A while moving). Add a capacitor (470 - 1000 µF) across the servo supply to avoid brownout resets of the ESP32.
