# Parameter `ServoRestAngle`
Default Value: `0`

!!! Warning
    This is an **Expert Parameter**! Only change it if you understand what it does!

Unit: Degree (0 - 180)

Angle of the servo when it is not pressing the button (only used if a GPIO is configured in `servo` mode, see `IO13` parameter).
The servo moves to this angle after the press and on startup.
